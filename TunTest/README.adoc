= Erste Schritte eines IPv6 Stacks

[.lead]
Fürs Erste wird nur macOS arm64 unterstützt.

== Bauen und ausführen

[source,sh]
----
dotnet publish -c Release -r osx-arm64 --self-contained
sudo ./bin/Release/net9.0/osx-arm64/publish/TunTest
----

== IP-Adresse zuweisen

Aktuell bekommt die Schnittstelle im Stack die `fd00::2/64`, der Client kann daher erstmal die `fd00::1/64` haben. Das ist fürs Erste erstmal _fix_ :)

[source,sh]
----
sudo ifconfig utun10 inet6 fd00::1/64 up
----

== Ping testen
